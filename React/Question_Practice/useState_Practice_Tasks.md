# useState Practice Tasks (Build Only)

1.  Create a counter with "Increase", "Decrease", and "Reset" buttons.
2.  Make a button that toggles between showing and hiding a paragraph.
3.  Create a theme switcher using useState.
4.  Build a controlled input that updates text live as the user types.
5.  Show how many characters the user typed in an input box.
6.  Create a password field with a button to show/hide the password.
7.  Build buttons that change the page background color using state.
8.  Create a multi-step form (step 1 → step 2 → step 3) controlled with
    state.
9.  Make a list where the user can add items using a text field.
10. Allow users to delete any item from the list using a button.
11. Render a checkbox and display "Checked" or "Not Checked" based on
    state.
12. Build a counter that increments by 5 instead of 1.
13. On button click, generate and store a random number in state.
14. Make buttons to increase and decrease the font size of some text.
15. Open and close a modal using useState.
16. Create 3 tabs and switch content based on selected tab.
17. Toggle a button label between "Login" and "Logout".
18. Build a form that stores name, email, and age in state.
19. Render multiple counters and maintain each counter's state
    separately.
20. Show the selected option from a dropdown using state.
