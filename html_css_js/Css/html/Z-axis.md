| Function    | Works in | What it does                         |
| ----------- | -------- | ------------------------------------ |
| `rotate()`  | 2D only  | Spins around Z-axis (default for 2D) |
| `rotateZ()` | 3D       | Spins around Z-axis (explicit)       |
| `rotateX()` | 3D       | Flips up/down                        |
| `rotateY()` | 3D       | Flips left/right                     |
