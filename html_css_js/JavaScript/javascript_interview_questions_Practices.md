# 🧩 Feature-Based JavaScript Interview Questions

## 🔹 Basic & Intermediate

1. Build a button that increases a counter every time it’s clicked and resets after reaching 10.
2. Implement a search bar that filters results in real time from an array of objects.
3. Implement a debounced search input that calls an API only after 500ms of inactivity.
4. Build a simple To-Do list with add/edit/delete operations stored in localStorage.
5. Implement a dark/light mode toggle and persist the theme using localStorage.
6. Create a modal/popup that opens and closes with animations.
7. Fetch data from a public API, handle loading/error states, and render it.
8. Implement infinite scrolling using Intersection Observer API.
9. Build an accordion component that opens one section at a time.
10. Create a tab component (Profile / Settings / Notifications).

## 🔹 Intermediate to Advanced

11. Build a registration form with client-side validation.
12. Implement sorting and pagination for a product list.
13. Create a draggable list to reorder items.
14. Build a simple pub/sub (EventEmitter) system.
15. Chain async operations using Promises (fetch → transform → display).
16. Retry an API call up to 3 times if it fails.
17. Throttle a scroll event to trigger once every 200ms.
18. Implement a memoization utility function.
19. Write a deep clone utility without using Lodash.
20. Render a virtualized list showing only visible rows for performance.
