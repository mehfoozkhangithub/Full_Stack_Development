steps:-

1. npm init -y
2. install all the packages like axios, webpack see on og website of that.

        npm install --save-dev webpack
        npm install --save-dev webpack-cli
        npm i axios

3. create 2-dir dist, src 
4. crate 2 files index.jsx inside src and index.html inside dist dir,..
5. create the file to config the webpack file name `webpack.config.js` inside this file you have to write the code below.
 note :- {
  "presets": [
    [
      "@babel/preset-env",
      {
        "targets": {
          "edge": "17",
          "firefox": "60",
          "chrome": "67",
          "safari": "11.1"
        },
        "useBuiltIns": "usage",
        "corejs": "3.6.5"
      }
    ]
  ]
}
