### Using These in CSS

To apply an icon with CSS `::before` or `content`:

```css
.my-icon::before {
  content: '\f061'; /* example: fa-arrow-right */
  font-family: 'FontAwesome'; /* or "Font Awesome 5 Free" depending on your version */
  font-weight: 900; /* use solid weight if necessary */
}
```
